# Room Chat API

## Project Description
Room Chat is a backend RESTful API designed to power a real-time discussion platform. It facilitates the creation of chat rooms, topic-based discussions, and user interactions. This project is built using Django and the Django REST Framework (DRF), serving purely as a backend service that returns JSON data to be consumed by separate frontend clients (web or mobile).

## Tech Stack

* **Language:** Python 3.12+
* **Framework:** Django 5.1.5
* **API Toolkit:** Django REST Framework 3.15.2
* **Database:** SQLite (Development) / PostgreSQL (Production)
* **Authentication:** Token-based Authentication
* **Server:** Gunicorn
* **Static Files:** WhiteNoise
